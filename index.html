Configuración · Enlace MQTT (HiveMQ Cloud)

La contraseña y la Active Key solo se guardan si marcas "Recordar", y únicamente en el navegador de este dispositivo (nunca en GitHub). Mientras estés conectado, la demo se oculta; vuelve a aparecer al presionar "Desconectar". Usa "Borrar Key guardada" para que este sitio olvide tu Key. HiveMQ: el usuario necesita suscripción a rack01/# y publicación en rack01/cmd/ventilador. Adafruit IO: escribe tu username y tu Active Key; el servidor se rellena solo (io.adafruit.com, puerto 443). No escribas la Key dentro del archivo ni la subas a GitHub.
